# لُقطة · Luqta

تطبيق أندرويد بواجهة عربية لتنزيل الفيديو والصوت وصور المنشورات داخل الهاتف باستخدام **yt-dlp وFFmpeg وQuickJS**.

**الإصدار الحالي: 1.6.1 · Android 10 أو أحدث · ARM64**

## تنزيل التطبيق

- [تنزيل APK مباشرة](https://github.com/Hassan20030/Luqta/releases/download/v1.6.1/Luqta-Android.apk)
- [صفحة الإصدار والكود المصدري](https://github.com/Hassan20030/Luqta/releases/tag/v1.6.1)

ثبّت التحديث فوق النسخة السابقة للاحتفاظ بالسجل والإعدادات. يلزم السماح بتثبيت التطبيقات من مصدر الملف في أندرويد. بصمات الملفات في [SHA256SUMS](downloads/SHA256SUMS).

## المميزات

- تنزيل الفيديو بصيغة MP4 أو WebM، والصوت بصيغة MP3 أو M4A.
- اختيار الدقة وFPS المتاحين من المصدر، حتى 2160p و120 FPS عند توفرهما معًا.
- صور المنشورات كاملة، واختيار الجودة الأصلية أو درجات أقل دون قص أو تكبير اصطناعي.
- تنزيل ألبومات إنستقرام وتيك توك من رابط واحد، حتى 50 صورة بترتيب المنشور.
- الوقف والاستكمال وطابور التحميل والسجل والحذف والفتح والمشاركة.
- نسخة تيك توك بصيغة MP4 وترميز H.264/AAC، مع متابعة تقدم التحويل وإلغائه وإعادة مشاركة النسخة المحفوظة.
- حفظ الفيديو والصوت والصور عبر MediaStore، دون إذن شامل لملفات الهاتف.
- مظهر فاتح وداكن وأيقونات تيك توك ويوتيوب وإنستقرام.
- HTTPS وفحص روابط التنزيل والتحويلات والعناوين العامة، ومعالجة FFmpeg للملفات المحلية فقط.

بعض الروابط والجودات قد يرفضها المصدر. التطبيق لا يرفع جودة الملف أو FPS اصطناعيًا، ولا يتجاوز DRM. قوائم التشغيل والبث المباشر غير مفعّلين. AutoHotkey يخص ويندوز ولا يدخل في نسخة أندرويد.

## الكود والبناء

التعليمات المفصّلة واختبارات التنزيل والحماية في [README_AR.md](README_AR.md). يستخدم المشروع Java 17 وAndroid SDK 36 وBuild Tools 35.0.0 وECJ 3.38.0، ويُبنى بسكربت Python دون Gradle.

```bash
python3 scripts/build.py --sdk /absolute/path/to/android-sdk --ecj /absolute/path/to/ecj.jar \
  --keystore /private/path/release.p12 --key-alias your-alias \
  --password-file /private/path/password.txt
```

مفتاح توقيع التطبيق وكلمات مروره **غير موجودين في هذا المستودع**. لبناء نسخة بتوقيعك استخدم مفتاحًا خاصًا خارج المشروع. تحديث النسخة الحالية مباشرة يحتاج شهادة التوقيع نفسها. البناء عبر GitHub Actions يدوي ويتطلب إعداد أسرار التوقيع الخاصة؛ نشر الإصدار الجاهز لا يحتاجها.

## التحقق

اجتازت النسخة فحوص المحرك والصور والألبومات والحماية على Linux، وفحوص Java ومنطق الواجهة باستخدام jsdom. تم التحقق من توقيع APK ومحاذاته وتطابق مواده مع الكود. تفاصيل التحديث في [ملاحظات الإصدار](docs/release-1.6.1.md).

لم يُختبر APK على هاتف أو محاكي فعلي؛ تشغيل ARM64 وتسجيل دخول المصدر والحفظ والإشعارات على الهاتف تحتاج تجربة فعلية. الحزم المصدرية القديمة التي سبقت فصل التوقيع كانت تحتوي مفتاح تطوير؛ إزالته من النسخ الجديدة لا تلغي نسخًا قديمة سبق مشاركتها.
